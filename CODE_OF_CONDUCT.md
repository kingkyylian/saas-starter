# Code of Conduct

This project expects professional, respectful collaboration.

## Expected Behavior

- Keep feedback specific, technical, and actionable.
- Avoid harassment, personal attacks, discriminatory language, and repeated
  off-topic arguments.
- Respect maintainers' time and project scope.
- Do not post secrets, tokens, customer data, or private webhook payloads.

## Enforcement

Maintainers may edit, hide, or delete comments; lock threads; close issues; or
block users who violate these expectations.

Security reports should follow `SECURITY.md`, not public issue threads.
